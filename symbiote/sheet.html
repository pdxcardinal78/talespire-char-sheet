Spirekeeper

Bring a D&D Beyond character into TaleSpire.

Open your character on D&D Beyond, click the Spirekeeper toolbar button, then Copy. Private characters work — it uses your signed-in session.

No extension? Import by hand
  1. Paste the character link

    This route needs the character set to Public on D&D Beyond. The extension does not.

  2. Open that URL and copy the JSON
    —

    D&D Beyond sends no CORS headers, so this panel can't fetch the URL itself. Open it in your browser, select all, copy, and paste it above.
